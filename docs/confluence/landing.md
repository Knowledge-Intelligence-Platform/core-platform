# Knowledge Intelligence Platform

## Welcome to KIP

Knowledge Intelligence Platform, also known as KIP, is a reusable foundation for building knowledge assistants. Teams can use the same platform code in their own AWS environment and connect their own approved documentation, so people can ask questions in everyday language and receive clear, grounded answers.

For example, Application A can adopt KIP for its own organization without building a knowledge assistant from scratch. The intended source options include Confluence spaces and Amazon S3 content; the current integration uses Confluence through Amazon Bedrock Knowledge Bases.

This space documents the shared platform. KIP’s own knowledge assistant is its first example deployment, not the only use of the platform.
